# ---------------------------------------------------
# 3. Helper to merge positive and negative word sets
# ---------------------------------------------------
def combine_frequencies(base, stress, stress_multiplier=1.0):
    combined = dict(base)
    for word, freq in stress.items():
        combined[word] = int(freq * stress_multiplier)
    return combined

* Out of the vicious loop
** Managing tasks in the long run: 4 rules
:PROPERTIES:
:CUSTOM_ID: rules
:END:

- *Use your system* -- put all the tasks and notes there\\
  {{{script(Do not spread things across email/paper/computer/own head)}}}
- *Make it a habit* to plan the day\\
  {{{script(if using agenda\, open it daily; if daily checklist\, write it daily)}}}
- *Prioritize* -- you cannot do every possible idea\\
  {{{script(nobody can "conquer" todo list in the long run; accept that some thing will never be done)}}}
- *Plan for emergencies* -- if things go wrong, plan the recovery\\
  {{{script(No system can every cover all possible life events. Accept that *things will go wrong*)}}}

** Use your system consistently

- If you manage tasks in Org, do it in Org
  - Not in your head
  - Not in email inbox + Org
  - Not spread across notebooks, computer, etc
- At least, computer-related tasks should be managed in the same way
- This is especially critical for social media that is designed
  to be attention sunk [fn::{{{tiny(Inspired by Cal Newport\, "Digital Minimalism: Choosing a Focused Life in a Noisy World")}}}]
- Ideally, task management should be the first place to reach out
  when not sure what to do next
- This minimizes distractions

* Rule 4: Have a recovery plan when life happens



** Even with the best system, things /will!/ go wrong

- Life always brings surprises
- Any habit, including task management habits, can be broken
  - emergencies
  - power outage
  - unforeseen deadlines
  - simply low mood
- When things go wrong, tasks will accumulate (in life as well)

** Recovery is all about priorities

- First, go back to the habit of using your task management
- Too many tasks means it is time to de-prioritize
  whole projects
- Unimportant things become "SOMEDAY"
- Important, but not absolutely 100% urgent
  are put on "HOLD"
- Time blocking controls attention span
- Weekly review allow trimming down the number of tasks
